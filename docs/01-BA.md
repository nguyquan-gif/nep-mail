# Nếp Mail — product contract

Status: private alpha, not a commercial release. Independent Nếp product; no data or credentials from other deployments. Original implementation; Keila source is not incorporated.

## Users and boundaries

An administrator creates workspaces and controls membership. Editors manage contacts and campaigns. Viewers can inspect data. Every business query must authorize workspace membership server-side. Nếp HR and Nếp Business are optional API clients; no automatic access to their databases.

## Alpha acceptance

1. Workspace creation, switching and persistent records; admin/editor/viewer authorization.
2. Contact creation, validated CSV import, deduplication, consent provenance, tags and suppression. Imports never restore an unsubscribed address.
3. Plain-text email composer with branded HTML rendering, escaped personalization, template selection, preview and HTML export.
4. Campaign drafts, audience preflight, immutable recipient snapshot on queueing, cancellation, manually triggered due-batch processing and per-recipient delivery states.
5. Delivery disabled by default. Real delivery requires explicitly enabled transport, sender, signing secret and publicly reachable unsubscribe URL. Synthetic example.invalid addresses are never sent.
6. Signed unsubscribe tokens: GET displays confirmation; POST unsubscribes. Check suppression again immediately before SMTP submission.
7. Workspace-scoped integration tokens shown once and stored hashed. Incoming events are deduplicated and cannot silently grant marketing consent.
8. Audit trail and truthful reporting: SMTP acceptance is not inbox delivery. No fabricated opens/clicks or performance metrics.
9. Same core runs on hosted D1 and self-hosted Node/SQLite. No hosted account required for self-host mode.
10. Tests cover authentication boundaries, isolation, RBAC, injection/escaping, consent, import replay, cancellation, scheduling, unsubscribe and integration replay.

## Deferred commercial gates

Public multi-customer signup, billing enforcement, verified sender onboarding, bounce/complaint ingestion, automatic durable scheduling, abuse controls at scale, backup restore drill, independent security review, accessibility audit and live inbox delivery UAT. Self-host SMTP is the delivery path. Postfix can deliver directly without an external delivery service. The private hosted preview does not send email. Integration contract is implemented here; connecting real HR/Business deployments is a separate rollout.

Do not label this release production-ready, or open the repository publicly, until the release checklist is satisfied and the owner selects a license.
