# Supporting Nếp Mail

Nếp Mail is free, self-hosted, and has no paid tier. Every feature is in the same
repository under AGPL-3.0 — nothing is held back for sponsors.

If the tool replaced a monthly subscription for you, or saved you a weekend of
wiring, you can send something back. If it did not, keep your money; the project
works either way.

## Where the money actually goes

Not to a company — there is no company. It pays for:

- the domain and the small server that build the releases and run the demo;
- a paid inbox or two used to test deliverability, because Gmail and Outlook
  treat a self-hosted sender differently and that has to be measured, not guessed;
- review of the ten interface translations by native speakers, which is currently
  the weakest part of the project (the translations are AI-assisted);
- time: an evening spent on a bug is an evening not spent elsewhere.

Donations do not buy features, priority support, or a say in the roadmap. Issues
are triaged the same way whether or not someone has sponsored.

No platform fee, arrives instantly, works from any Vietnamese banking app. Scan

```
Ngân hàng:     TPBank

Chủ tài khoản: NGUYEN MANH QUAN
```

This is a receiving account: the QR can only send money to it, never take money
out. It is published deliberately, because a bank transfer is the only option
here that costs neither side a fee.

## If you would rather not pay

That is a perfectly good answer. Equally useful:

- **Star the repository** — it is how other people find the project at all.
- **Report a bug** with the exact steps, the version from `/healthz`, and what you
  expected. Reproducible reports save more time than money.
- **Fix a translation** — open a pull request against `src/core/locales/`. Native
  review is the thing this project needs most.
- **Tell one person** who runs a small newsletter and is tired of per-contact
  pricing.
